# Berg Systems

Marketing website for Berg Systems, a local web-design and business-tools service.

## Run locally

```bash
npm start
```

The site listens on `PORT` when provided, or port `3000` by default.

## Railway

Railway can deploy this repository directly from GitHub. The project uses only Node's built-in HTTP server, so no dependency install is required.

The contact form currently logs submissions to the Railway service console. Connect it to email or a database before relying on it for production leads.
